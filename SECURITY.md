# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — do not open a public
issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting: go to the repository's
**Security** tab and choose **Report a vulnerability**. If that is unavailable,
contact a maintainer directly.

When reporting, please include:

- A description of the issue and its potential impact.
- Steps to reproduce (a minimal spec / manifest and the commands run).
- The affected version or commit.
- Any relevant logs or configuration (with secrets redacted).

## What to expect

- We will acknowledge your report and begin investigating.
- We will keep you informed of progress toward a fix.
- We ask that you give us a reasonable opportunity to release a fix before any
  public disclosure, and we will credit you if you wish.

## Supported versions

Converge is pre-1.0 and under active development. Security fixes are applied to
the `main` branch; there are no long-term support branches yet.
